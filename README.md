# 🎧 Spotify Clone (Practice Project)

This is a simple **Spotify-style music player UI** made with **React + Vite**.  
I built this project to practice React, Tailwind CSS, React Router, and the Context API.

---

## 🧱 Tech Used

- React
- Vite
- Tailwind CSS
- React Router (`react-router-dom`)
- React Context API & Hooks (`useState`, `useRef`, `useContext`)

---

## 🚀 How to Run This Project

1. Clone the project:

```bash
git clone https://github.com/student-aashish/spotify-clone.git
cd spotify-clone

📂 Main Features
	•	Sidebar similar to Spotify
	•	Home display with albums / playlists
	•	Bottom music player bar
	•	Global audio player using React Context
	•	Play / Pause button with dynamic icons
	•	Basic seek bar UI (ready for time control logic)
	•	Responsive layout for desktop (and basic support for smaller screens)

🎛 Player Context (Short Summary)

The file src/context/PlayerContext.jsx stores the player state:
	•	audioRef – global <audio /> element reference
	•	seekBg / seekBar – refs for the seek/progress bar
	•	track / setTrack – current song data
	•	playStatus – playing or paused
	•	play() / pause() – functions used in the Player component
```
